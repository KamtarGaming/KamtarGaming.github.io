# Mon Badgeage

Application Android locale de suivi du temps de travail par badge NFC. Elle enregistre les arrivées, pauses et départs, calcule les heures et le solde hebdomadaire, affiche l’historique dans un calendrier et permet d’importer les relevés de l’entreprise depuis une photo.

Toutes les données restent sur le téléphone, sans compte ni synchronisation.
